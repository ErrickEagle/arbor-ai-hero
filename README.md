# Arbor AI — particle hero

An AI SaaS hero section built with Three.js: ~56k particles fly in to form a sphere, then morph between six shapes (tree, hand, solar system, human, box, triangles) on click, with cursor repulsion, a rippling reflective floor, depth-of-field shading and animated UI.

Single static file — open `index.html` or deploy as a static site (no build step).
